# Evidence-core pilot program

## Ideal participants

Healthcare software startups using synthetic test data, compliance consultancies, university security labs, and nonprofit health organizations with a bounded cloud-audit use case.

## Four-week scope

Week 1 defines one evidence request, current manual method, source exports, success measures, privacy boundary, and named evaluator. Week 2 configures read-only normalizers and validates a synthetic or approved non-production sample. Week 3 runs the same evidence request manually and with the tool. Week 4 independently verifies a pack, reviews false matches, and signs an outcome summary.

## Measures

- active minutes for the same task and reviewer expertise;
- records processed, rejected, and deduplicated;
- correlation true/false positives and false negatives on an agreed labeled subset;
- query latency and pack verification result;
- setup time, defects, and usability score;
- whether the organization permits its name or only an anonymous description.

## Exit criteria

Delete or return provided exports, revoke credentials, document unresolved defects, and deliver a participant-controlled result. Participation does not require endorsement. No production PHI is needed for the healthcare reference pilot.
