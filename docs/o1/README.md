# Public-impact and O-1 evidence workstream

This folder organizes truthful, independently verifiable project evidence. It is an engineering and publication plan, not immigration legal advice and not a claim that any O-1 criterion has been satisfied. Counsel should decide which evidence is material and how it is presented.

## Completed locally

- independently packageable Apache-2.0 open core with named authorship;
- technical preprint and architecture decisions;
- executable synthetic benchmark with accuracy and throughput measures;
- signed, hash-addressed, tamper-detecting evidence packs;
- Azure SQL, Entra ID, Key Vault, Kubernetes, and GitHub Actions normalizers;
- non-PHI healthcare reference architecture;
- hash-chained metric ledger and a claim register;
- pilot, expert-review, speaking, and award submission kits.

Use [PUBLISH_OPEN_CORE.md](PUBLISH_OPEN_CORE.md) to release only the isolated subtree while preserving real Git authorship.

## Requires real third parties

- publication to a public repository and durable release archive;
- independent pilots and signed outcome reports;
- external contributors, reviews, citations, installations, talks, awards, or press;
- independent timestamp, security assessment, and benchmark reproduction;
- legal advice and petition preparation.

Never backfill, purchase, or imply external recognition. Store the original artifact, date, URL, author identity, and permission for each claimed outcome.
