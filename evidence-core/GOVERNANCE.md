# Governance

## Roles

- **Maintainer:** reviews changes, manages releases, and publishes the roadmap.
- **Contributor:** submits code, documentation, benchmark results, or reviews through attributable commits.
- **Security reviewer:** privately evaluates security reports and coordinates disclosure.

Akshay Jagadeesh is the initial maintainer. New maintainers require two accepted material contributions, documented review participation, and an approval recorded in a public governance issue.

## Decisions

Architecture changes require an Architecture Decision Record. Security-sensitive changes require two-person review once a second maintainer exists. Until then, releases must include automated tests, a published diff, and a signed release manifest.

The project does not rewrite contributor history, attribute generated code to another person, sell maintainer status, or accept undisclosed benchmark sponsorship.
